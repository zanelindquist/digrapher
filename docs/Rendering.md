## Viewing Space
- Use polar coordinates for all calculations since we are centering this object around the center of the viewport
- Polar coordinates will only be transformed into pixel values when it's time to render the shape
- Center of the viewing space should be 0

## Dots
- Dots should be positioned in an *n* sided regular polygon
- The shape should be centered around the middle of the viewing space
### Style
- Dots should be the primary color
### Behavior
- Dots should be pressable and pull up a list of neighbors and the type of relations they share with them
